## Conflicts and unresolved evidence

- **First slice:** one reviewer proposes crossing all confirmed integration boundaries immediately; the other recommends a PDF pilot and separate spikes. Recommend the latter for speed, with a written milestone that prevents the pilot from being mistaken for a complete release.
- **Data storage:** classify owned and derived data now; do not mandate two databases or an off-host backup target before the privacy decision and restore measurements.
- **Anki:** agree on a single grading authority, but note push, log import, Android behavior, and identifier stability remain untested. No existing Anki collection should be used for experiments.
- **Research MCP:** code inspection found potential reuse and significant reproducibility/side-effect constraints. No local API call, fixture test, benchmark, full license review, or dependency security audit occurred.
- **Mobile:** online responsiveness is the near-term phone/tablet test. Offline packaging, cache durability, event replay, and deletion behavior require later actual-device evidence.
- **Learning:** deterministic selection tests establish coherent behavior, not educational efficacy. Delayed assessment remains a separate evaluation task.
