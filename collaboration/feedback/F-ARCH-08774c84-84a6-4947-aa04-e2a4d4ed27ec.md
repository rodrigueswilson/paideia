## Finding and rationale
The MVP loop starts from "select authorized PDF", so it can pass without crossing any confirmed integration boundary. It has no Zotero identity (REQ-03), no Obsidian/Kindle annotation path (REQ-03), no Anki boundary (REQ-05 runs "separately") and no phone (REQ-02). Those boundaries are exactly the contracts that shape the schema: ExternalReference, annotation authorship, scheduler domain and event origin. A slice built on loose files therefore validates the least risky part and postpones the parts that are expensive to change, which invites rework of the identity and event tables.

## Evidence (URLs, observed tests, or explicit unknowns)
- Baseline: MVP "select authorized PDF ... Anki integration experiment and Android offline sync experiment may run separately"; the Deferred list; the domain model's ExternalReference and Annotation; Integrations table "read-only import initially".
- UNVERIFIED: Zotero 7 exposes a local read-only HTTP API that mirrors the Web API. I could not confirm this on https://www.zotero.org/support/dev/zotero_7_for_developers; the audit should check Zotero's own documentation or forum announcement. A fallback that needs no API: read a copied snapshot of a *test* Zotero profile's database.

## Proposed change and alternatives
Recommended: keep the loop, but cross each confirmed boundary thinly, using test data only.
- Take the source from a dedicated test Zotero library or profile, read-only, with the item key stored as an ExternalReference.
- Use one synthetic Obsidian note in the Kindle plugin's format (the audit identifies the format). It produces Annotation records that separate the learner from the author, linked to the same Source.
- Push approved card objects one way to a disposable Anki profile and import its review log (see F-ARCH-a5ad9adf-ccf1-4e7e-ab75-42473d4f1de6).
- The phone and tablet use the host UI online over the LAN, with no offline mode, so the responsive gate is checked on real devices.

Explicit exclusions remain: offline use and sync, German content, the graph UI and Neo4j, OCR, the adaptive recommender, and any write to Zotero, Obsidian or Anki production data.

Alternative: keep the PDF-only slice, but require its schema to include the ExternalReference and scheduler-domain fields, and finish the integration spikes before slice two. Cheaper in the first week, with a higher risk that the spikes force schema changes.
