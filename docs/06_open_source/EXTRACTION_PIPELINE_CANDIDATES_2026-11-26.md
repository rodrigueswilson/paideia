# Existing extraction pipelines to evaluate — 2026-11-26

Status: source review only. No new package or hosted service was installed, called with a PDF, or adopted. Features below come from maintainers' documentation and are not comparative accuracy evidence.

| Candidate | Relevant existing capability | Fit and open question |
|---|---|---|
| [Docling](https://docling-project.github.io/docling/concepts/confidence_scores/) | Local conversion already tested here; built-in document/page confidence grades for parsing, layout and OCR can guide review or another pipeline. [PDF options](https://docling-project.github.io/docling/reference/pipeline_options/) configure OCR, tables, layout, backend text and image handling. | Best first reuse candidate. Installed 2.82.0 returned confidence on the second paper, but graded page 2 `excellent` despite a visually confirmed joined-word caption. Its table quality score is not implemented. Preserve independent passage/quotation checks; record confidence alongside run metadata before testing routing thresholds. |
| [Unstructured](https://github.com/Unstructured-IO/unstructured/blob/main/unstructured/partition/strategies.py) | Its `auto` PDF strategy chooses a text-layer fast path or OCR path and switches to layout extraction when table structure is requested. The [core repository license](https://github.com/Unstructured-IO/unstructured/blob/main/LICENSE.md) is Apache 2.0. | Useful alternative routing baseline. Its automatic strategy is primarily input/option selection; it does not establish that extracted claims or captions are correct. Exact version, dependency/model licenses, telemetry behavior and local configuration need review before a controlled benchmark. |
| [MinerU](https://opendatalab.github.io/MinerU/usage/tiers/) | Local tiers span fast native extraction, OCR/formulas/tables without a VLM, and more expensive VLM-assisted layouts. It has an SDK, API and structured outputs. | Worth a later side-by-side test if Docling cannot meet quality/cost targets, especially figures or formulas. Current repository uses a [custom MinerU license](https://github.com/opendatalab/MinerU/blob/master/LICENSE.md) based on Apache 2.0 with extra terms; exact version, model weights, platform cost and terms require adoption review. |
| [Azure Document Intelligence Layout](https://learn.microsoft.com/azure/ai-services/document-intelligence/prebuilt/layout?view=doc-intel-4.0.0) | Hosted OCR/layout extraction includes text, tables, figure regions, captions and confidence. | A possible external benchmark, not a local default. Sending any private source to a cloud service would require explicit owner consent and a data policy; cost and provider terms also need review. No Paideia document was sent. |

## Practical conclusion

There are more complete off-the-shelf pipelines than the current Paideia proof. The shortest next step is to reuse Docling's existing confidence report together with the passage/table/figure checks already tested, then measure escalation on representative authorized PDFs. The second paper demonstrates why a high document/page grade cannot alone approve a quote or figure. Evaluate a second local engine only when a specific quality gap remains, using the same frozen source PDFs and reference checks. None of the reviewed products eliminates the need to verify consequential quotations or extracted figure values.
